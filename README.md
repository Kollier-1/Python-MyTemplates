## About the Project

This repository contains a collection of Python exercises developed as part of my programming studies. The main goal is to strengthen my programming fundamentals through practical exercises, problem-solving, and the implementation of different programming concepts.

The exercises cover basic calculations, conditional statements, loops, data structures, and file handling. Each program focuses on a specific problem and provides an opportunity to practice writing readable and organized code.

## Topics Covered

- **Python Fundamentals:** Variables, data types, input/output, arithmetic operations, and mathematical calculations.
- **Conditional Statements:** `if`, `elif`, and `else`.
- **Loops:** `for`, `while`, and nested loops.
- **Lists and Data Structures:** Lists, vectors, matrices, and dictionaries.
- **Data Processing:** Counting, classification, averages, sums, and other calculations.
- **File Handling:** Reading from and writing to text files.
- **Problem-Solving:** Applying programming logic to practical exercises.

## Getting Started

### Prerequisites

Install Python 3 on your computer. You can download it from the official website:

[Download Python](https://www.python.org/downloads/)

### Clone the Repository

Open a terminal and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the URL of this repository.

Navigate to the project directory:

```bash
cd python-exercises
```

### Run an Exercise

Navigate to the folder containing the exercise you want to run, then execute the Python file:

```bash
python path/to/exercise.py
```

For example:

```bash
python 01-python-basics/temperature_converter.py
```

Depending on your system, you may need to use `python3` instead of `python`.

Some exercises require user input through the terminal. Follow the instructions displayed by each program.
